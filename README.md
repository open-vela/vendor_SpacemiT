# SpacemiT Platform Support for openvela

\[ English | [简体中文](README_zh-cn.md) \]

This repository adapts **SpacemiT** RISC-V chip platforms for openvela, on
the `dev-ai-contest-2026` contest branch. The repository is currently in
the early bootstrap stage; chip-side and board-side adaptation code will
land through PRs incrementally.

## Boards Pending Porting

| Board | SoC | Porting guide |
|-------|-----|---------------|
| MUSE Pi Pro | SpacemiT K1 (M1) | [boards/k1/muse_pi_pro/README.md](boards/k1/muse_pi_pro/README.md) |

## Contributing

Board adaptation code is welcome via PR. See the "How to Contribute a Port"
section in the target board's README for the detailed steps.
