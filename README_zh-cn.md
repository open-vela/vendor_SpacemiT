# SpacemiT 平台对 openvela 的支持

\[ [English](README.md) | 简体中文 \]

本仓库为 openvela 适配 **SpacemiT**（进迭时空）的 RISC-V 芯片平台，基于
`dev-ai-contest-2026` 大赛分支。仓库当前处于初始建设阶段，芯片层与板层的
适配代码将通过 PR 陆续合入。

## 待适配开发板

| 开发板 | 芯片 | 适配指引 |
|--------|------|----------|
| MUSE Pi Pro | SpacemiT K1（M1） | [boards/k1/muse_pi_pro/README_zh-cn.md](boards/k1/muse_pi_pro/README_zh-cn.md) |

## 贡献

欢迎通过 PR 提交板级适配代码，具体步骤参考目标板 README 中的"如何贡献适配"
章节。
